# Документация проекта: Анализ влияния мутаций SARS-CoV-2 на динамику пандемии

## 1. Общее описание
Данный проект представляет собой аналитический инструмент для сопоставления эпидемиологических данных (избыточная смертность, заболеваемость) с биологическими данными (появление и распространенность конкретных мутаций вируса). Цель проекта — выявить наиболее опасные мутации и оценить их вклад в тяжесть протекания пандемии.

## 2. Используемый стек технологий
*   Язык программирования: Python 3.x
*   Библиотеки обработки данных: pandas, numpy
*   Визуализация: matplotlib, seaborn
*   Статистический анализ: scipy.stats (корреляционный анализ)

## 3. Описание структуры данных
Проект оперирует тремя основными массивами данных:
1.  Эпидемиологические показатели: Временные ряды подтвержденных случаев заражения и смертей.
2.  Избыточная смертность (Excess Mortality): Оценка разницы между ожидаемой и фактической смертностью для выявления скрытых потерь.
3.  Геномные данные (Variant Surveillance): Доля распространенности мутаций (например, N501Y, L452R, P681R) во времени.

## 4. Архитектура программного решения

### 4.1. Препроцессинг и фильтрация
*   Очистка данных: Обработка пропусков и приведение дат к единому формату.
*   Нормализация: Приведение показателей смертности и распространения мутаций к шкале [0, 1] для корректного сравнения (используется метод MinMaxScaler).
*   Расчет избыточности: Вычисление коэффициента недоучета (отношение избыточной смертности к официальной).

### 4.2. Алгоритм скоринга мутаций
Центральной частью кода является расчет интегрального показателя опасности (Composite Danger Score) для каждой мутации по формуле:
$Score = (W_{mortality} \times M_{norm}) + (W_{spread} \times S_{norm})$
где:
*   $M_{norm}$ — нормализованный вклад в смертность.
*   $S_{norm}$ — вклад в скорость распространения.
*   Веса $W$ установлены как 0.7 для смертности и 0.3 для распространения.

### 4.3. Блок визуализации
Код включает генерацию следующих типов графиков:
*   KDE Plot: Распределение плотности избыточной смертности.
*   Correlation Heatmap: Матрица взаимосвязи между присутствием мутации и летальностью.
*   Scatter Matrix: Классификация мутаций по четырем зонам риска (Low, Medium, High, Critical).

## 5. Основные функции и методы
*   calculate_excess_factor(): Определяет кратность превышения реальной смертности над официальной.
*   analyze_mutation_impact(): Выполняет корреляционный анализ между ростом доли конкретной мутации и всплесками смертности.
*   generate_danger_matrix(): Категоризирует мутации на основе их биологического влияния.

## 6. Результаты и выводы
*   Коэффициент избыточности: Среднее значение превышения смертности составило ~2.2 раза.
*   Идентификация угроз: В ходе анализа мутации N501Y и P681R (Delta) были классифицированы как критически опасные.
*   Динамика Omicron: Выявлено, что мутации группы Omicron (S371L, S373P) имеют аномально высокую скорость распространения при значительно сниженном вкладе в показатель летальности по сравнению с предыдущими штаммами.

## 7. Инструкция по развертыванию
1.  Установить зависимости: pip install pandas numpy matplotlib seaborn scipy.
2.  Разместить исходные датасеты в корневую папку с проектом.
3.  Последовательно запустить ячейки в файле main-2.ipynb.
